# Налаштування Firebase Storage

## Проблема з завантаженням зображень

Якщо зображення не завантажуються, перевірте наступні налаштування в Firebase Console:

### 1. Правила безпеки Firebase Storage

Перейдіть в Firebase Console → Storage → Rules і встановіть наступні правила:

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true; // Для тестування - дозволяє всі операції
    }
  }
}
```

**УВАГА:** Ці правила дозволяють всі операції. Для продакшену потрібно налаштувати більш безпечні правила.

### 2. Перевірка налаштувань проекту

1. Перейдіть в Firebase Console → Project Settings
2. Перевірте, чи правильно налаштований Storage Bucket
3. Переконайтеся, що Storage увімкнено

### 3. CORS Проблеми

Якщо виникають CORS помилки (як у вашому випадку), це означає проблеми з налаштуваннями Firebase Storage:

#### Рішення 1: Перевірте Storage Bucket
1. Перейдіть в Firebase Console → Storage
2. Переконайтеся, що Storage увімкнено
3. Якщо не увімкнено, натисніть "Get started" → "Start in test mode"

#### Рішення 2: Перевірте правила безпеки
1. Перейдіть в Storage → Rules
2. Встановіть правила як показано вище
3. Натисніть "Publish"

#### Рішення 3: Альтернативне рішення (Base64)
Якщо CORS проблеми залишаються, додаток автоматично використовує base64 для збереження зображень. Це працює, але зображення будуть більшими в розмірі.

### 4. Тестування підключення

1. Відкрийте адмін-панель вашого додатку
2. Натисніть кнопку "Тестувати Storage"
3. Перевірте консоль браузера на наявність помилок

### 5. Можливі проблеми та рішення

#### Проблема: "Permission denied"
**Рішення:** Перевірте правила безпеки Firebase Storage

#### Проблема: "Bucket not found"
**Рішення:** Перевірте налаштування Storage Bucket в Firebase Console

#### Проблема: "Network error" або CORS помилки
**Рішення:** 
1. Перевірте підключення до інтернету
2. Переконайтеся, що Storage увімкнено
3. Перевірте правила безпеки
4. Якщо проблема залишається, використовуйте base64 (автоматично)

### 6. Безпечні правила для продакшену

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /images/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null; // Тільки для авторизованих користувачів
    }
    match /content/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

### 7. Діагностика

Якщо проблема залишається:

1. Відкрийте Developer Tools (F12)
2. Перейдіть на вкладку Console
3. Спробуйте завантажити зображення
4. Перевірте, які помилки з'являються в консолі
5. Скопіюйте та надішліть помилки для подальшого аналізу

### 8. Поточний стан

**Важливо:** Через CORS проблеми з Firebase Storage, додаток налаштований на автоматичне використання base64 для збереження зображень. Це означає:

✅ Зображення будуть завантажуватися та зберігатися
✅ Всі функції працюватимуть
⚠️ Зображення будуть більшими в розмірі (base64)
⚠️ Firebase Storage не використовується

Для вирішення CORS проблем потрібно правильно налаштувати Firebase Storage в консолі.
